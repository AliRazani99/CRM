# راه‌اندازی پروژه NEXUS ERP

## پیش‌نیاز

- Node.js نسخه 18 یا بالاتر
- npm

## اجرا

در پوشه پروژه دستورهای زیر را اجرا کنید:

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال، معمولاً `http://localhost:5173`، را باز کنید.

## قابلیت‌های نسخه فعلی

- داشبورد BI پویا بر اساس داده‌های عملیات
- ثبت کالا و کنترل SKU تکراری
- موجودی دو انبار، رزرو، نقطه سفارش و هشدار کمبود
- انتقال کالا بین انبارها
- ثبت فروش چندقلمی، پرداخت کامل/ناقص و ایجاد بدهی مشتری
- ثبت مشتری و تسویه مطالبات
- ثبت تأمین‌کننده
- ثبت خرید چندقلمی و تخصیص Landed Cost
- حساب ریالی و CAD
- تبدیل ارز و ثبت خودکار گردش حساب
- ذخیره داده‌ها در LocalStorage مرورگر
- بازنشانی داده‌های نمونه از دکمه بالای صفحه

## نکته معماری

این پروژه یک Prototype فرانت‌اند است و هنوز Backend، پایگاه داده، احراز هویت و API واقعی ندارد. لایه Context طوری جدا شده است که در مرحله بعد بتوان عملیات را به API جنگو متصل کرد.
