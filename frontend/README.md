# NEXUS ERP BI Prototype

نمونه تعاملی React برای مدیریت فروش، خرید، موجودی دو انبار، مشتریان، تأمین‌کنندگان، بدهی، حساب‌های ریالی و CAD و داشبورد BI.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید.

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

داده‌ها در LocalStorage مرورگر ذخیره می‌شوند. از منوی کاربر می‌توان داده‌های آزمایشی را بازنشانی کرد.
